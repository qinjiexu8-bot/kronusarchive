# Kronus Archive

An independent, source-led field guide to *Warhammer 40,000: Dawn of War IV*.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production

```bash
npm run build
npm start
```

## Deploy to Vercel

Import this repository into Vercel. The framework is detected as Next.js and
uses the standard `npm run build` command.

Set `NEXT_PUBLIC_SITE_URL` to the final production origin, for example:

```text
https://your-domain.com
```

This value is used for canonical metadata, structured data, `robots.txt`, and
the XML sitemap.

## Content policy

Pre-launch information must be backed by primary sources. Hands-on statistics,
build orders, and strategy claims require a game version, repeatable method,
and verification date.
